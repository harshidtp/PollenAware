# PollenAware

PollenAware is a personalised allergy monitoring platform that provides
environmental insights, personalised allergy-risk assessment,
notifications, and analytics based on pollen and weather data.

## Architecture

PollenAware follows a microservice architecture derived using
Domain-Driven Design (DDD).

### Services

- Authentication Service
- User Service
- Environmental Monitoring Service
- Risk Assessment Service
- Notification Service
- Analytics Service

## Technology Stack

- React / Next.js
- Node.js
- Express.js
- PostgreSQL
- REST
- Publish/Subscribe
- RabbitMQ
- Docker
- Kubernetes
